# CO2Body frontend

React 19 single-page application for https://co2body.com, built with Create React App/react-scripts 5. GitHub: breathIQ/ai-affiliate-content-steven-Frontend. Locally recorded Vercel project: co2body-frontend. Reviewed 2026-09-04 at 926e7b4; live Vercel settings and deployed commit were not authenticated in this review.

The backend is a separate Next.js repository, breathIQ/co2body-api, serving https://api.co2body.com. Frontend changes do not deploy backend routes, databases, cron jobs or provider credentials.

## Development

Use the Node version configured in Vercel; this package does not pin one. Run npm ci --legacy-peer-deps from the repository root, then npm start (normally http://localhost:3000). npm run build produces build/. The checked-in vercel.json uses npm install --legacy-peer-deps and CI= npm run build; the CI setting means warnings do not necessarily fail the hosted build. On PowerShell, use $env:CI='' before npm run build if reproducing that behavior.

The API URL is HARDCODED in src/services/contants.js (the filename is intentionally spelled that way): https://api.co2body.com/api/v1. There is currently no environment-variable override. For local backend work, deliberately change that constant in your working copy to http://localhost:3100/api/v1, run the backend separately, and inspect the diff before release. Starting this frontend unchanged connects it to the production API.

No literal process.env reads were found in the tracked frontend source. Do not add private API keys to a browser application; a future REACT_APP_* variable would be embedded in its build.

## Authentication and contracts

Axios reads localStorage.access_token. The API retains Laravel Sanctum-compatible tokens; do not rename the storage key or change its format in one repository only. The current interceptor does not clear credentials or redirect on 401 because those statements are commented out. A stale login may therefore need explicit user recovery.

ProtectedRoute's role argument is an EXCLUDED role, despite the name: it renders children when user.role_id differs from the argument. Missing storage defaults to {}, so the !user check does not reject it. Several library paths are also marked public. This is not a trustworthy access-control boundary; the backend must enforce identity, role and ownership on every sensitive request. Review this code deliberately before changing the route schema; do not document it as conventional role-based allowlisting.

Generation and publishing may charge credits, call paid providers or post publicly. The backend owns those operations. Async image generation can return pending_render and requires polling the post endpoint. Test the state transition and failure UI, not just the initial successful response. When updating a response shape, update both the service wrapper and every consuming page/modal.

## Verification and deployment

- Build with npm run build; inspect warnings as well as the exit code.
- npm test -- --watchAll=false runs the existing tests. src/App.test.js still asserts the starter text "learn react" and is stale relative to the real application; it is not useful product coverage. This documentation pass does not change or claim to pass that test.
- Check direct navigation and refresh on /login, /u/dashboard and an admin path. BrowserRouter needs hosting fallback to index.html. vercel.json does not explicitly define a rewrite, so verify the configured framework/output behavior in Vercel rather than assume deep links work.
- Use test accounts and the intended backend environment for login, generation and billing checks. A page loading is not proof of successful publishing or payments.
- Confirm the Vercel project is co2body-frontend, its output is build/, and its production source branch matches the intended commit before release.

For recovery, redeploy the last known-good frontend version. This does not reverse API or database changes. Keep the frontend/backend pair compatible. Document any new storage key, public config variable, route, or polling state in this README and regenerate the source reference.
